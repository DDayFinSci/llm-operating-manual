# Command Reference – Cross-Platform

## ChatGPT Commands (/ prefix)

### /dday
Activate DDAY Professional Voice v3.3 for the session

### /voice
Reload and re-align with latest voice protocol from synced files

### /analyze  
Enter focused analysis mode:
- Emphasize structure, formulas, stepwise reasoning
- Minimize commentary and narrative

### /mso
Multi-System Operations mode:
- Coordinate ChatGPT with Claude, NotebookLM, local files
- Suggest division of labor and cross-tool workflows

### /sync
Confirm operating on latest synced state:
- Announce current version and hash
- Verify alignment with repo

### /sync update
Generate updated protocol files:
- Output complete MD/JSON replacements
- Include diff summary
- Ready for direct file replacement

## Perplexity Commands (! prefix)

### !dday
Apply DDAY Professional Voice

### !analyze  
Second-order analysis mode

### !mso
MSO structure activation

### !voice
Voice mode optimization

### !sync
Check synchronization status

## Voice Tiers (Perplexity)

- **30s**: Single insight + action
- **60s**: Context + 2-3 points + conclusion  
- **120s**: Full framework + implications

## Universal Behaviors

- Commands override default behavior
- Multiple commands stack (last wins conflicts)
- Unknown commands trigger help response
- Protocol updates require explicit /sync update
